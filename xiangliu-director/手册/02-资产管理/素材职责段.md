# 素材职责段

本文件管提示词中的【素材职责】段。资产管理模块产出本段内容，交由 [04-提示词](../04-提示词/提示词模版.md) 组装。

## 决策流程：推理清单 → 核对资产 → 有就绑 → 缺了问 → 再落笔

1. 写【素材职责】前，先从本段剧情推理完整需求清单：人物、场景、道具逐项列出，不能遗漏。
2. 拿清单逐项核对项目资产文件夹（用户已命名好的人物、场景、道具文件）。
3. 清单中有对应资产 → 写素材条目：`@图片N：用于人物/场景/道具的哪些特征，不采用图片中的哪些部分。`
4. 清单中有、资产文件夹缺失的项 → **停下询问用户：文生还是提供图片？** 经确认后再落笔，禁止擅自决定。
5. 文生时人物、场景、道具都要写文生条目，与素材条目并列。
6. 文生条目格式：`文生-<元素名称>，<描述>；`一个元素一条独立成行，不合并。
   文生人物必须带外貌描述（年龄/国籍/气质，服装属外貌一并写明）；文生场景、道具各带描述。
   文生人物的具体活动写在【人物位置】段，不写在文生条目里。

## 素材职责案例（写法以此为准）

有素材写法：

【素材职责】
@图片1：用于鱼摊内部布局、长凳、砧板、鱼台和摊内通道，不采用图片外的其他场景。
@图片2：用于女主的五官、发型与服装，不采用图片中的背景。
@图片3：用于男主的五官、发型与服装，不采用图片中的背景。
@图片4：用于儿子的五官、发型与服装，不采用图片中的背景。
@音频1：用于男主现场人声质感参考，不逐字复制原音频对白。

纯文生写法：

【素材职责】
文生-湖面，黄昏时分的宽阔湖面，金色水光粼粼；
文生-木船，一叶木船浮在湖面，船板随水轻晃；
文生-女主，娇俏的亚洲20岁年轻女性；
文生-男主，帅气的美国20岁年轻男性；

# 镜头写法

本文件管【镜头N】的镜头层全套规则：镜头段怎么写（时长、五槽句序、分段衔接、
起幅自检、自检脚本、成品格式）、站位与场景布局（多人物主次、场景布局锁定）、
镜头语言（三槽用词、机位、景别、运镜、相邻变化、对白正反打、落幅承接）。
配套：[旁白与对白.md](旁白与对白.md)（文本层：切段与对白拆分）、
[情绪演绎规则.md](情绪演绎规则.md)（表演）。
写每一段镜头前，本文件全文通读，读完才动笔。

## 镜头时长

单镜 1–3 秒切镜，最长不超过 4 秒。
每行旁白的时长按 [时长计算.md](../01-剧本分析/时长计算.md) 回读执行，禁止凭记忆另算。
旁白再长就切多镜共讲这一句的事，禁止单镜硬扛长旁白；
切镜的目的与镜数规则按 [旁白与对白.md](旁白与对白.md)「一句旁白内怎么切」执行。
段尾校验——段内各镜总时长小于段内字幕总跨度时，末镜补 0.5 秒。
对白不走字幕时间戳：每句对白的时长与语速基准按
[时长计算.md](../01-剧本分析/时长计算.md) 回读执行；
怎么拆、情绪快慢怎么调，按 [旁白与对白.md](旁白与对白.md)「对白怎么拆」执行。

## 分段与衔接

Seedance 2.5 单段视频上限 30 秒，超长剧集按段生成，段落时长依据旁白时长表的行时长划分；
段由旁白行累计时长切，30秒为上限非配额（详见 [旁白与对白.md](旁白与对白.md)「段怎么切」）。
连续剧情（同场景同时间流）的多段衔接，按 [旁白与对白.md](旁白与对白.md)「连续段怎么衔接」
执行锚定手法；场景/时间跳转的段才用换主体衔接：
上一段收尾主体与下一段开场主体不同（如上段收在女主，下段开在男主或场景元素），
以主体更替实现自然衔接；或按旁白语义的画面切换点断段。
AI 视频模型无记忆力：跨段连贯不依赖模型记忆，只依赖资产锚定与主体衔接设计。

## 五槽句序

【镜头N】段按五槽写，一槽一件事，写完就停，不加新内容：
①承接上一镜落幅（每段首镜省略）
②起幅：主体＋动作＋空间关系（入画人物间的相对位置）
③表演：动机与核心情绪一句起头，微表情动作与肢体语言按情绪演绎规则落笔
④台词：说什么＋语气修饰＋声音变化（无台词的镜头省略）
⑤落幅：收在情绪结果态

## 可见与画外

画内画外的判断按「多人物主次」执行；正反打看不见说话人时，台词写画外音。

## 主体与代词

提示词内以主体名为主（男主/恶龙等逐镜点名），代词只是适当衔接；
禁止满篇代词导致指代模糊，也禁止满篇主体名导致重复刷屏。

## 起幅自检

每镜起幅必须写清三样：主体、动作、空间关系（入画人物间的相对位置）。
光线和环境背景不用每镜重复：同一场戏里它们不变，
在【人物位置】或首镜定下方向，光向必须与【镜头风格】的影调同一口径；
之后只在镜头用到光或环境说话时才写（如轮廓光勾发缘、逆光走剪影），
且只许借用已锚定的光，禁止引入新光源、改变时间或天色。
光线禁止特效光词（丁达尔、体积光、辉光、金光万丈类）。
材质写关键物（服装/道具的质感），按需出现。
起幅三样过完才许写落幅。

## 自检脚本

每段分镜写完，运行自检脚本：
python scripts/check_shots.py 提示词文件.txt
脚本按六把锁检查：写法（景别/机位槽格式）、变化（相邻至少两项）、
连续（同主体禁连拍三镜、禁机位来回切）、时长（超4秒、时间轴重叠空档、
段落总时长超30秒）、禁词（死死、紧绷等硬禁项）、
骨架（镜2起正文以承接开头、每镜含落幅）。
有报警改镜重跑；报错时回读对应模块重组，六锁全过才许组装。

## 成品格式

每个镜头正文连写一个自然段，段内不断行、不掺多余空格；
镜与镜之间空一行。落盘成品与聊天交付同一标准：复制即可用，不带显示用的折行。
txt尾部附旁白-画面对照表（一镜一行：镜号｜主体｜景别｜旁白原文｜画面），
格式与规则见 [旁白与对白.md](旁白与对白.md)「旁白-画面对照表」；对照表垫底，正文完整不动。

## 多人物主次

有戏份的人物（说话、有表情动作反应的）逐人写清；两人同框时，可以用分号连在一段里。
无戏份的路人合并成一行：谁在背景干什么，动作持续。禁止给无戏份人物写微表情与对白。

例（拥抱戏，两人同框，分号衔接）：
女主再绷不住涌上的酸楚与感动，向前一步，额头抵上男主胸口，右手抓住他衣襟；男主手臂合拢把她圈进怀里，下巴轻抵她发顶，眼睛望向海面。

例（酒吧路人，合并一行）：
调酒师在背景擦着杯子，两名客人坐在吧台边喝酒，处于景深状态。

反例（路人违规加戏）：
调酒师皱着眉头看了他们一眼，擦杯子的手停了下来。——给了路人微表情，动作也没持续。

背景与画外判断：入画（可见）才写，未入画的就不写。
入画对手在前景的（正反打、过肩），写成前景：对手的虚化肩背占画面哪一缘，主体面部清晰。
主体背景有背景人物的，写成：谁在背景干什么，处于景深状态——如"店员在背景擦着柜台，处于景深状态"。
未入画但动作必须锚定的（看、听、指、对白对象），写明"画外"：如"看向前方画外的男主"——除锚定外，画外一个字不提。

## 场景布局锁定

同场景的多段视频中，人物站位、道具位置、光线方向保持一致；
在不改变布局的前提下，构图、景别、机位可自由发挥，
华丽运镜与冲击性构图全面放开，服务情绪与剧情推进。

## 三槽位格式锁死

【镜头N｜时间｜主体景别｜机位｜运镜】的用词法则。
主体景别、机位、运镜三个槽位的格式锁死；禁止自造词。

- 景别词库定死：大全景、全景、中景、中近景、近景、特写
- 机位词库定死：正面、左侧、右侧、左肩后、右肩后、腰后、背后
  ＋低角度、俯视、贴地＋航拍俯视机位、第一人称机位
- 运镜：真实专业术语都可用，禁自造词；例子与组合写法见「运镜怎么选」
- 航拍视角是运镜，归运镜槽；航拍俯视机位是机位，归机位槽，两个词不混用。

正文永远开放：真实存在的专业术语都可按"进阶镜头语言"公式翻译后使用。

## 机位怎么写

机位＝摄影机放在谁的哪个方向，最后加"机位"两字。
方向词七个：正面、左侧、右侧、左肩后、右肩后、腰后、背后。
方向以被贴者本人的身体为准——男主右侧＝男主右手边，不是观众看的右边。
左肩后、右肩后、腰后＝越过他的肩或腰拍对面的人，前景肩背虚化占画面一边。
高度接在后面：低角度、俯视、贴地；平视不写。

【男主近景｜正面机位｜固定镜头】
【男主近景｜女主左肩后机位｜固定镜头】
【女主近景｜正面机位+低角度｜缓慢推】

人名：单人镜不写名（正面机位）；过肩必须写名（女主左肩后机位）；
双人、群像贴着谁写谁（男主右侧机位）。
特写拍什么正对什么：手机屏幕特写用正面机位；手、脚用俯视机位。
航拍俯视机位、第一人称机位，剧情需要才用。

禁止：家具进机位槽（"茶几机位"×）；拍男主贴到无关人身上（"女主左侧机位"×），过肩除外。
正文把机位翻译成画面：从女主左肩后拍男主，女主虚化的肩背占画面右缘，男主面部清晰。
机位变没变按拍摄面判定：主体的正面、左侧、右侧、背面四个面。
机位含"肩后"＝从对手肩后拍主体的脸，归入主体的正面；
机位含"腰后"＝从对手腰后拍主体的脸，归入主体的正面；
机位含"背后"＝镜头正对主体的后背，归入主体的背面；
机位含"左侧"＝镜头拍主体的左脸，归入主体的左侧面；
机位含"右侧"＝镜头拍主体的右脸，归入主体的右侧面；
机位含"正面"＝镜头正对主体的脸，归入主体的正面。
高度词（低角度、俯视、贴地）只是拍摄说明，不算拍摄面，也不参与机位变化判定。
同主体相邻两镜，机位变了＝拍摄面变了——面没变，机位词怎么换都不算变。

合格：正面中景 → 左侧近景（面变＋景别变，两项）。
不合格：女主正面中近景 → 女主近景·男主左肩后机位——
        两个机位都在拍女主的正面，面没变，只变景别一项。
不合格：正面中景 → 正面低角度近景（面没变，只变景别一项——高度不算变化）。

## 前景遮挡怎么拍

前景遮挡物（花瓶、门缝、纱帘、玻璃、栏杆）不是机位，机位照常在被拍的人身上。
遮挡物写进起幅：在前景什么位置、占画面哪一缘、清晰还是虚。
焦点转移用移焦，按"进阶镜头语言"的公式写在正文；摄影机不动，运镜槽写固定镜头。

例：
【镜头N｜0-2s｜男主中景｜正面机位｜固定镜头】：起幅透过桌上的白瓷花瓶拍男主，花瓶清晰占画面左缘，男主在瓶后面部模糊。镜头移焦，焦点从花瓶移到男主脸上，花瓶虚成色块，男主五官清晰。男主要在气势上压住对手，笃定里不带商量，他十指交叠搁在桌面，眼皮半压着开口："Fifteen percent. Final." 落幅男主靠回椅背，视线仍落在对手脸上。

禁例：【镜头N｜0-2s｜男主中景｜花瓶前景机位｜固定镜头】——遮挡物进了机位槽，自造词。

## 景别怎么写

景别＝主体＋一个景别词，一镜只写一个主体：
男主近景、女主特写、男女主双人中近景、手机屏幕特写、门特写、海岸线大全景。

三种禁止：
一、禁止没有主体的景别——"大全景"×，要写"海岸线大全景"。
二、禁止两个东西缝进一个景别——"手机与UI弹窗卡片中近景"×，UI、弹窗写进正文。
三、禁止三人以上列名字——"男主、女主、莱拉、男二中景"×。

三人及以上，景别槽只写一个主要人物——女主中景；
画面里还有谁、站在哪，写进正文起幅。
群像没有主要人物的环境大场面，主体写场景——庭院大全景、海岸线大全景。

## 群像怎么拍

群像镜头只用来交代——开场、转场、收尾时把人和位置展示给观众：
主要人物三人以上同框，景别用全景及以上。
正文只写构图——从哪拍、谁在哪、什么状态，不写表演（交代镜省略表演槽），
全段站位由【人物位置】承担，正文不再重复报位置。

三人以上要演戏，拆成单人、双人的正反打，
一镜一个焦点人物，谁说话拍谁，反应切对方。
路人、店员不算群像，永远按背景人物规则处理。

例：
【镜头1｜0-3s｜庭院全景｜航拍俯视机位｜固定镜头】：起幅俯拍庭院全貌，女主拖着行李箱站在院子中间，男主垂手立在门边，父母并肩站在台阶上，行李箱的拉杆还立着没收回。落幅全员静止，行李立在女主手边。

## 运镜怎么选

运镜词库是例子不是上限：真实专业术语都可用，禁自造词。
常见的例子：固定镜头、推、拉、摇、移、跟、环绕、俯冲、后拉、上摇、
手持拍摄、一镜到底、希区柯克变焦、航拍视角、FPV、子弹时间、回弹变速。
加速度修饰随便加：缓慢推、匀速环绕。

单运镜还是组合运镜，看画面需要：交代清楚，一个运镜就够；
烘托氛围、丰富画面、打斗炫技等等，就用组合运镜，
真实术语之间用"＋"连接。

边界只有两条：
一、禁止自造词。
二、希区柯克变焦不与人物行走、群像运动叠加——这是验证过的卡顿跳变来源。
除此之外组合不设名单：打斗、炫技、大场面，画面需要就上。

## 热门运镜（直接写）

画面有多个主体时，必须说明运镜围绕谁、从哪里开始、到哪里结束。

| 运镜方式 | 建议写法 |
|---|---|
| 一镜到底 | 说明镜头连续经过的主体、空间和事件顺序 |
| 希区柯克变焦 | 说明主体保持的大小，以及背景空间被拉近或推远的效果 |
| 航拍视角 | 说明俯视高度、移动方向和需要展示的环境范围 |
| FPV | 说明第一人称飞行或穿行路径、速度和转向 |
| 子弹时间 | 说明被冻结或放慢的动作，以及镜头环绕方向 |
| 手持拍摄 | 说明跟拍对象和晃动程度，避免只有"手持感"而没有镜头目标 |
| 回弹变速 | 说明动作在哪个节点加速、减速或回弹，以及最终停留状态 |

## 进阶镜头语言（真实术语开放，写法有律）

真实存在的专业镜头术语都可用，冷门热门都算；禁止自造词。
小众、含义不统一或模型可能不熟悉的术语，保留术语名称，同时按公式翻译成可直接观察的画面变化：

专业术语 + 作用主体 + 画面变化 + 前景/背景关系 + 方向或速度

示例：移焦：焦点从前景树叶平滑转移到背景人物。树叶逐渐虚化，背景人物的面部由模糊变得清晰。

## 摄影表示例

1. 浅景深人像，<糕点师>的眼睛和面部保持清晰，身后的玻璃罐和灯光虚化成柔和圆形散景。
2. 追跟摄影，镜头与<滑板者>同速水平移动，人物保持清晰，街边墙面形成从右向左的水平拖影。
3. 黄金时刻，暖色低角度阳光从<登山者>左后方照入，山脊地形形成较长阴影。
4. 自然暗角，画面四角逐渐变暗，中心<钢琴演奏者>的亮度和肤色保持正常，不出现黑色边框。
5. 甩镜转场，第5秒镜头快速向左横移；前景书架完整整屏遮挡时切换到下一场景，切换后镜头继续保持向左运动。

## 精确转场

写清：触发时刻、遮挡物、镜头运动方向、切换方式、切换后保持的构图或运动趋势。

## 相邻镜头怎么变

写完一镜，和上一镜比：主体、机位、景别。
三样里至少两样要变；只变一样不合格，一样都不变更不合格。

禁止连续三个或三个以上镜头为同一主体。

旁白是连续单人镜头时，同一主体连着的镜头，景别和机位必须变化：
合格：正面中景 → 左侧近景（拍摄面变＋景别变，两项）。
不合格：正面中景 → 左侧中景（拍摄面变了，景别没变——只变一项）。
不合格：正面中景 → 正面低角度近景（面没变，只变景别一项——高度不算变化）。

连续长剧情只描述一个人时，通过穿插特写来解决"禁止连续三个镜头拍摄同一主体"：
在人物和他正在用的东西之间交替——撕信拍撕信的手，踱步拍走动的脚，哪里在演戏拍哪里。
旁白有动作就跟旁白拍；旁白没写动作（旁白长、画面没啥可拍），可以自己设计，
前提只有一个：不违背旁白——旁白在打电话，就不能拍吃饭。
特写的主体（身体部位、道具、物件）计数单独算，不与人物连着数——人物永远连不到三镜。

禁止的事，一条一条写明白：
一、禁止连续三个或三个以上镜头为同一主体。
   反例：正面中景 → 正面低角度近景 → 俯视特写——连着三镜都是同一主体，禁止。
二、禁止同一主体的机位来回切。
   反例：正面 → 左侧 → 正面——先这个方向，换一个，又切回来。
   反例：正面 → 左侧 → 右侧——从一边直接换到另一边。
三、禁止同主体两镜之间机位和景别没有都变。
   反例：男主近景 → 男主中景——景别变了，机位没变。
   反例：正面中景 → 正面近景——景别变了，机位没变。

例（单人段落的合法切法）：
男主中景 → 男主手部特写（他正在撕信） → 男主近景
主体依次是：男主 / 男主手部 / 男主——没有任何主体连拍三镜。

## 对白正反打

对白拆好了（拆分与时长基准见 [旁白与对白.md](旁白与对白.md)「对白怎么拆」），镜头这么切：
对白必须正反打：说话人和听话人镜头交替，打电话、现场对话一律如此。
禁止长时间把镜头停留在说话人一个人身上，必须有对方反应镜头。
前半句镜内说，切到对方反应，后半句画外音接着说——
说话人不在画面里时，台词写画外音。

对白正反打时，镜头的声音跟着剧本走，两种情况：
一、剧本是连续对话：正打切画外音的时候，禁止给无声音镜头——
   反打镜上必须有说话人的画外音。
二、剧本在话与话之间插了旁白，旁白又是关于反应动作的：
   必须给相应的反应镜头，旁白配在上面——这镜没有对白、没有画外音，
   只有旁白，这是剧本要求的演法，不算空镜。
判定一句话：这一镜的声音是什么？对白口型、说话人画外音、旁白——
剧本给什么就上什么；三个都没有的镜头才是空镜，禁。

例：

一、连续对话：
剧本：女："你昨晚去哪了？"　男："我出差了。"
镜1｜女主近景｜正面机位｜口型同步："你昨晚去哪了？"
镜2｜男主近景｜女主右肩后机位｜口型同步："我出差了。"
（说话人交替，每镜都有对白口型）

二、话与话之间插旁白：
剧本：女："你昨晚去哪了？"
旁白：他的沉默就是答案。
男："我出差了。"
镜1｜女主近景｜正面机位｜口型同步："你昨晚去哪了？"
镜2｜男主特写｜左侧机位｜无声反应：他的眼神躲开了。
　← 旁白配在这镜上；切到左侧特写，面和景别都变了
镜3｜男主近景｜女主右肩后机位｜口型同步："我出差了。"
（镜2→镜3同主体男主：拍摄面左侧→正面变＋景别特写→近景变，两项达标）

三、女的说很长一段，中间切反应：
剧本：女："你昨晚不在家，电话也不接，消息也不回。你知道我一个人在家有多害怕吗？我以为你出事了。"
镜1｜女主近景｜正面机位｜口型同步："你昨晚不在家，电话也不接，消息也不回。"
镜2｜男主特写｜左侧机位｜反应＋女主画外音："你知道我一个人在家有多害怕吗？"
镜3｜女主近景｜男主右肩后机位｜口型同步："我以为你出事了。"
（长对白拆在语义断口，每镜都有声音，拍摄面逐镜真变）

## 落幅与承接

落幅是上一镜的终点，承接是下一镜的起点，两个点必须咬合。

1. 落幅照实写收尾：人停在哪里、在做什么——收回手、摸摸她的头，都照写；只有否定式不行，"没有伸向女主"会被模型渲染成"伸向女主"，落幅只写看得见的。
2. 承接照着落幅接：落幅收在什么，承接就接什么，带上主体，从落幅往下走，别把上一镜的动作重新演一遍，也别添新动作。

对照案例（酒馆那场戏）：
落幅：落幅男主收回了手，垂在桌沿。
承接：承接上一镜男主收回手垂在桌沿，起幅从女主肩后拍他。
禁例：落幅女主的目光落在杯沿上，没有看男主。——"没有看"是否定，改写：落幅女主的目光落在杯沿上，睫毛还湿着。

## 数值原则

光圈、焦距、快门数值可写入，但画面的可见结果比数值更明确。

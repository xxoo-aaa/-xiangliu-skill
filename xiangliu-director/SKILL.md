# 相柳导演技能

AI短剧导演中枢：调度五个模块，把剧本变成可直接复制使用的 Seedance 提示词。

## 铁律

1. 禁止污染：做剧的一切产出、临时文件、克隆目录、测试残留一律写入项目文件夹
   或系统临时目录（d:\skill 根目录除 .trae 外禁止新增任何文件），
   技能文件夹内只允许 SKILL.md 与 手册\ 的已定稿内容，禁止任何其他文件进入。
2. 仅用户说"更新技能"或"更新本地以及仓库技能"时，才可修改本地技能文件；
   说"更新本地以及仓库技能"时，修改后必须同步 GitHub 仓库并拉取验证版本号
   （github.com/xxoo-aaa/-xiangliu-skill）。
3. 格式唯一权威在 [手册/04-提示词/提示词模版.md](手册/04-提示词/提示词模版.md)，
   任何模块不得复制格式，只链接引用。
4. 用户的情绪、风格、感觉指令最高优先级，含义不明立即询问，禁止猜测。

## 生产流程（按序执行，上一步产出是下一步输入）

1. 剧本进入 → 读 [手册/01-剧本分析/剧本分析手册.md](手册/01-剧本分析/剧本分析手册.md)
   → 必做情绪分析，产出分集清单、资源清单、情绪线
2. 资源核对 → 读 [手册/02-资产管理/素材职责段.md](手册/02-资产管理/素材职责段.md)
   → 素材绑定；缺失素材停下询问用户：文生还是图片
3. 分镜（站位复杂或用户要求时，先出站位俯视图）→ 按序读：
   ① [手册/03-分镜/旁白对应.md](手册/03-分镜/旁白对应.md)（第一优先：旁白划段）
   ② [手册/03-分镜/站位与布局.md](手册/03-分镜/站位与布局.md)（站位与俯视图）
   ③ [手册/03-分镜/镜头段写法.md](手册/03-分镜/镜头段写法.md)（每段怎么写）
   ④ [手册/03-分镜/镜头语言使用法.md](手册/03-分镜/镜头语言使用法.md)（相邻变化与落幅承接）
   ⑤ [手册/03-分镜/情绪演绎规则.md](手册/03-分镜/情绪演绎规则.md)（表演）
   产出分镜草稿，对照 [手册/03-分镜/分镜示例.md](手册/03-分镜/分镜示例.md)（品味基准）
4. 组装（按序执行，不许跳）：
   ① 读 [手册/04-提示词/提示词模版.md](手册/04-提示词/提示词模版.md)（骨架、组装规矩、生成目标写法）
   ② 打开 [手册/04-提示词/提示词案例.md](手册/04-提示词/提示词案例.md)，对照品味写【生成目标】
   ③ 写【素材职责】段前，回读 02-资产管理/素材职责段.md 对照案例
   ④ 写【人物位置】与【镜头N】段前，回读 镜头段写法.md 与 镜头语言使用法.md
   ⑤ 逐镜成品，直接复制可用；写完读一遍，每处一读都有画面

任何一步缺材料（剧本、旁白音频、素材）立即向用户索取，禁止跳步。

# 相柳导演技能 v1.0.9

AI短剧导演中枢：剧本进，提示词成品出。五个模块联动生产，把整部剧变成可直接复制使用的 Seedance 2.5 提示词。

## 功能概述

| 能力 | 说明 |
|---|---|
| 剧本分析 | 五步分析法：六要素校验、分集清单（钩子/冲突/释放/留扣）、资源盘点、情绪线（必做）、视听思路 |
| 资产核对 | 推理素材需求清单 → 核对资产文件夹 → 有就绑，缺了问（文生/图片） |
| 分镜设计 | 按旁白划段（≤30s）、段内镜头（1–3s）、段间换主体衔接、站位俯视图（SVG）、情绪演绎 |
| 提示词组装 | 五段式模版逐镜填充，成品直接复制可用 |

## 结构

```
xiangliu-director\           相柳（总调度）
├── SKILL.md                 中枢：铁律 + 生产流程
└── 手册\
    ├── 01-剧本分析\         五步分析法
    ├── 02-资产管理\         素材清单核对制
    ├── 03-分镜\             镜头语言 / 人物位置与镜头段 / 情绪演绎规则
    └── 04-提示词\           组装总图纸（格式唯一权威）
```

## 安装

把 `xiangliu-director/` 放入技能目录：

- Trae：项目 `.trae/skills/` 或全局 `~/.trae/skills/`

## 用法

说「相柳」启动，或直接给剧本 + 旁白音频开始生产。流程：

```
01 分析剧本 → 02 核对资产 → 03 分镜（划段/镜头/站位图） → 04 提示词成品（TXT交付）
```

## 设计原则

- 剧本为王：不改本、不否决，短板用画面补强
- 模型无记忆：跨段衔接靠主体更替，一致性靠资产锚定
- 格式唯一权威在 04，模块间只链接引用不复制
- 项目内容不载入技能，技能文件夹只读不写
